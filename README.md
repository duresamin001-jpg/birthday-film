# A Cinematic Birthday Film for Iman 🎬✨

A continuous full-screen, scroll-driven interactive birthday film website built with Vite, React, TypeScript, Tailwind CSS, Framer Motion, and Lenis smooth scrolling.

## 🌟 Features
- **Canvas-Driven Film Playback:** Seamless 60fps canvas frame renderer with coarse-to-fine progressive loading.
- **Watermark-Free Visuals:** 15fps WebP frame sequences in both 1080p (HD) and 720p (SD).
- **DWELL Remap Curve:** Mathematics-driven scroll deceleration that slows down the film while chapter stories and wishes are read.
- **Cinematic Motion & Lighting:** Letter-by-letter blur-up reveals, ambient sparkle trails, and frosted glass cards.
- **Fully Responsive:** Beautifully composed on desktop monitors and mobile screens.

## 🚀 Development & Build

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

## 🌐 Deploy to Vercel
1. Push this repository to GitHub.
2. Import the repository into [Vercel](https://vercel.com).
3. Vercel automatically detects the **Vite** preset with build command `npm run build` and output directory `dist`.
4. Click **Deploy**.
